# Cheat Sheets

One page per area. You write them, and the Clerk only tidies them up.

After the interview, your agent copies the template below into this folder once for each area
(`a1-<name>.md`, `a2-<name>.md`, …) and adds that area's topics as section hints.

## Rules

1. Fill each page from memory, not from the book. Deciding what goes on it is part of learning it.
2. Don't copy someone else's notes. The way they organized it fits their memory, not yours.
3. After the weekly ritual, give your messy notes to the Clerk (prompt §10). It reorders, groups,
   and shortens them, but never adds anything. If it thinks something is wrong, it marks it
   `[CHECK]`.
4. Check every `[CHECK]` yourself in your authoritative source. Nothing unchecked stays on a sheet.
5. In the days before a test, these pages are all you review. If something isn't on the page,
   either it doesn't matter or you don't know it yet.
